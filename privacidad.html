Política de Privacidad

Respetamos la privacidad de tus datos personales.

1. Datos recolectados

Recolectamos datos básicos como nombre, teléfono y dirección para procesar pedidos.

2. Uso de los datos

Los datos solo se usan para envíos, soporte y uso interno.

3. Seguridad

Implementamos medidas razonables para proteger tu información.

4. No compartimos tu información

No vendemos ni compartimos tus datos con terceros.
